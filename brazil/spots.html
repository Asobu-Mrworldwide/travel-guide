リオデジャネイロ

山と海が織りなす絶景に、キリスト像とコパカバーナ海岸が揃うブラジル観光の顔。サンバとカーニバルの熱気が根付く旧首都
アクセス
ガレオン国際空港から市内中心部までタクシー・配車アプリで約40分
おすすめ時期
6〜9月の乾季
宿泊エリア
イパネマ／レブロン / コパカバーナ / ボタフォゴ
⭐
RIO 01世界遺産
コルコバードのキリスト像
710mの丘の頂に立つ新・世界七不思議のひとつ。両手を広げた姿からリオの街と入江を一望できる絶景スポット。

RIO 02世界遺産
ポン・デ・アスーカル（シュガーローフ山）
2基のロープウェイで登る奇岩の山。夕暮れ時は山頂から街と海が黄金色に染まる絶景を眺められる人気スポット。

RIO 03定番ビーチ
コパカバーナ／イパネマ海岸
波型の遊歩道が続く白砂のビーチ。ビーチバレーやフットボレイを楽しむ地元民と観光客が入り混じる、リオの日常の縮図。
Googleマップ →
RIO 04アートの階段
セラロン階段
チリ人芸術家が世界中のタイルで埋め尽くした約250段の階段。1段ごとに異なる色彩が続く、フォトジェニックな名物スポット。
Googleマップ →
RIO 05サッカーの聖地
マラカナン・スタジアム
ワールドカップの決勝も行われたブラジルサッカーの聖地。試合がない日もスタジアムツアーで内部を見学できる。

RIO 06世界最大級の都市林
ティジュカ国立公園
市街地を囲む世界最大級の都市林。滝やハイキングコースが広がり、展望台からはリオの街と海を一望できる自然のオアシス。

RIO 07海岸を一望する要塞
コパカバーナ・フォート
コパカバーナ海岸の南端に立つ要塞。海岸線を一望できる展望台があり、館内の老舗カフェ「コロンボ」でひと休みするのも定番。

RIO 08日帰りで行ける離島
イルハ・グランデ
リオから船で行ける美しい離島。透明度抜群のビーチと熱帯雨林トレイルが広がり、車の乗り入れ禁止で静かな時間が流れる。

サンパウロ

南半球最大の巨大都市。美食とアートシーンが集積する経済の中心地で、世界最大級の日系人コミュニティが根付く街でもある
アクセス
グアルーリョス国際空港から市内中心部まで車・バスで約40分〜1時間
おすすめ時期
4〜9月の乾季
宿泊エリア
ジャルジンス / ヴィラ・マダレーナ / アヴェニーダ・パウリスタ周辺
⭐
SP 01南米屈指の美術館
アヴェニーダ・パウリスタとMASP
サンパウロの目抜き通りに立つ、赤い柱で宙に浮くような外観が特徴の近代美術館。周辺は週末に歩行者天国となり賑わう。
Googleマップ →
SP 02美食市場
メルカドン（市営市場）
ステンドグラスが美しい歴史的市場。名物モルタデーラ・サンドイッチや南米各地のフルーツを味わえる、食べ歩きにぴったりのスポット。
Googleマップ →
SP 03グラフィティの名所
ベコ・ド・バットマン
ヴィラ・マダレーナ地区の路地を埋め尽くすグラフィティアート街。アーティストが今も描き替え続ける、生きたストリートアート空間。
Googleマップ →
SP 04市民の憩いの公園
イビラプエラ公園
オスカー・ニーマイヤー設計の建築群が点在する、サンパウロ市民憩いの大公園。週末は家族連れやジョギングをする人々で賑わう。
Googleマップ →
SP 05日系文化の街
リベルダーデ（日本人街）
赤い鳥居と提灯が並ぶ、世界最大級の日系人コミュニティが築いた街並み。週末の東洋市は日本食材や雑貨を扱う屋台で賑わう。
Googleマップ →
⭐
SP 06旧市街のシンボル
サンパウロ大聖堂（カテドラル・セ）
旧市街の中心に立つネオ・ゴシック様式の巨大聖堂。8,000人を収容できる内部空間と壮麗なステンドグラスが見どころ。
Googleマップ →
SP 07最古級の美術館
ピナコテッカ
ブラジル最古の美術館のひとつで、MASPと並ぶアート鑑賞の名所。19〜20世紀のブラジル絵画・彫刻の充実したコレクションを誇る。
Googleマップ →

フォス・ド・イグアス

世界三大瀑布のひとつイグアスの滝への玄関口。ブラジル・アルゼンチン・パラグアイの国境が接する三角地帯に位置する
アクセス
フォス・ド・イグアス空港から国立公園入口まで車・バスで約20〜30分
おすすめ時期
4〜9月の乾季
宿泊エリア
国立公園に近いホテル街道（Rodovia das Cataratas）沿い
⭐
IGU 01世界遺産
イグアス国立公園（ブラジル側）
大小275の滝が幅2.7kmにわたり轟音を響かせる世界遺産。遊歩道からパノラマで滝群全体を見渡せるのがブラジル側の魅力。
Googleマップ →
⭐
IGU 02大迫力のボートツアー
マクコ・サファリ（ボートツアー）
滝壺のすぐ下まで接近するスリル満点のボートツアー。全身ずぶ濡れ覚悟で「悪魔の喉笛」の水しぶきを間近に体感できる。
Googleマップ →
IGU 03野鳥の楽園
パルケ・ダス・アヴェス（野鳥公園）
オオハシやフラミンゴなど中南米の野鳥を間近で観察できる大型ネット式ビオパーク。イグアスの滝とあわせて訪れやすい立地。
Googleマップ →
IGU 04世界最大級のダム
イタイプ・ダム
パラグアイとの国境をまたぐ世界最大級の水力発電ダム。展望台から見る堤体のスケールは圧巻で、夜のライトアップツアーも人気。
Googleマップ →

サルバドール

ブラジル最初の首都として栄えた港町。カラフルな旧市街ペロウリーニョを中心に、アフリカ系文化と信仰が色濃く息づく
アクセス
サルバドール国際空港から旧市街まで車・バスで約40分
おすすめ時期
9〜3月の乾季
宿泊エリア
ペロウリーニョ周辺 / バーハ地区
⭐
SAL 01世界遺産
ペロウリーニョ歴史地区
パステルカラーのポルトガル植民地建築が丘の斜面に並ぶ世界遺産地区。カポエイラやサンバの生演奏が路上に響く活気ある街並み。
Googleマップ →
SAL 02黄金の教会
サン・フランシスコ教会
内部を覆う金箔装飾が圧巻のバロック様式教会。植民地時代の富の象徴とされる豪奢な内装は、ブラジル屈指の見応え。
Googleマップ →
SAL 03街のシンボル
エレヴァドール・ラセルダ
高台の旧市街と海沿いの下町を結ぶ、1873年開業のアールデコ調エレベーター。乗るだけで街のパノラマビューが楽しめる名物施設。
Googleマップ →
SAL 04工芸品市場
メルカド・モデロ
かつて奴隷貿易の税関だった建物を利用した工芸品市場。カポエイラの実演も行われ、バイーア土産を探すのに最適なスポット。
Googleマップ →
SAL 05都市型ビーチ
ポルト・ダ・バーハ海岸
旧市街から徒歩圏内にある都市型ビーチ。灯台を望む夕日スポットとしても人気で、地元の若者で賑わう気軽なビーチライフを味わえる。
Googleマップ →

オウロ・プレット

18世紀の金鉱で栄えたバロック建築の街。丘の斜面に教会と石畳の坂道が積み重なる、ミナス・ジェライス州随一の世界遺産都市
アクセス
ベロオリゾンテからバスで約2時間、サンパウロから国内線とバス乗継で約3〜4時間
おすすめ時期
4〜9月の乾季
宿泊エリア
中心部プラサ・チラデンテス周辺
⭐
OP 01世界遺産
サン・フランシスコ・デ・アシス教会
彫刻家アレイジャジーニョが手がけたロココ様式の傑作。曲線的なファサードと内部の壁画が見事な、ブラジルバロック建築の最高峰。
Googleマップ →
OP 02独立運動の史跡
プラサ・チラデンテスとインコンフィデンシア博物館
独立運動の志士チラデンテスの名を冠した中心広場。旧市庁舎を利用した博物館で、ブラジル独立運動の歴史を学べる。
Googleマップ →
OP 0318世紀の金鉱跡
ミナ・ダ・パッサジェン（古鉱山ツアー）
18世紀に実際に採掘されていた地下坑道をトロッコで巡るツアー。地底湖など幻想的な光景とともに、ゴールドラッシュの歴史を体感できる。
Googleマップ →

マナウス

アマゾン川流域最大の都市。熱帯雨林クルーズやジャングルロッジへの拠点で、ゴム景気時代のヨーロッパ調建築が今も残る
アクセス
リオ・サンパウロから国内線で約4〜5時間。他都市との直行便は限られる
おすすめ時期
6〜11月の乾季（水位が下がりビーチが現れる）
宿泊エリア
市街中心部、またはアマゾン川沿いのジャングルロッジ
⭐
MAO 01密林の中の歌劇場
アマゾナス劇場
19世紀末のゴム景気で栄えた富の象徴、密林の中に忽然と現れるヨーロッパ様式の歌劇場。ドーム屋根の陶器タイルはすべて欧州から運ばれた。
Googleマップ →
⭐
MAO 02自然が生む名物風景
二つの川の出会い（エンコントロ・ダス・アグアス）
黒褐色のネグロ川と黄土色のソリモンイス川が、水温と流速の違いから数kmにわたり混ざらず並走する不思議な現象。ボートツアーで間近に観察できる。
Googleマップ →
MAO 03熱帯雨林の宿泊体験
アマゾン・ジャングルロッジ滞在
熱帯雨林の奥に建つロッジに1〜2泊し、カヌーでのワニ探し・野鳥観察・先住民集落訪問を楽しむ定番アクティビティ。夜の虫や鳥の合唱も密林ならではの魅力。
Googleマップ →

レンソイス・マラニャンセス

純白の砂丘とエメラルドグリーンのラグーンが織りなす、2024年に世界遺産登録された北東部の絶景エリア。乾季限定で現れる幻想的な光景で知られる
アクセス
サンパウロ・リオから国内線でサンルイスへ、拠点の町バレイリーニャスまで車で約4時間
おすすめ時期
6〜9月限定（ラグーンが現れる季節）
宿泊エリア
拠点の町バレイリーニャス
⭐
LEN 01世界遺産
レンソイス・マラニャンセス国立公園
純白の砂丘が地平線まで広がる2024年世界遺産の絶景公園。雨季にはあちこちに透明なラグーンが現れる。
Googleマップ →
⭐
LEN 02定番の絶景ラグーン
ラゴア・アズール（ブルーラグーン）
透明度抜群のコバルトブルーのラグーン。人気ルート「ラゴア・アズール・サーキット」の主役で、遊泳も楽しめる。
Googleマップ →
LEN 03夕日の名所
ラゴア・ボニータ
砂丘の頂から沈む夕日を見渡せる、レンソイス随一の夕景スポット。刻々と染まる空とラグーンの色彩が美しい。
Googleマップ →
LEN 04砂漠の果ての漁村
アチンス
砂漠の最果てにひっそりと佇む小さな漁村。ハンモックで昼寝を楽しむ、旅の終着点にふさわしいのどかなリゾート。
