香港島

高層ビルと古い街並みが坂道で重なる香港の中心。ピークの夜景、廟、屋台の路地、海辺の町まで、半日ごとに表情が変わる
アクセス

空港↔市内

HKI 01夜景の名所
ヴィクトリア・ピーク
標高約550mの香港随一の展望スポット。ピークトラムで山頂へ上がり、高層ビルと海が広がる夜景を見渡せる。

⭐
HKI 02渦巻き線香
文武廟
文の神様と武の神様を祀る19世紀の道教寺院。天井から吊るされた巨大な渦巻き線香の煙が、堂内に満ちる。
Googleマップ →
HKI 03街歩き
ミッドレベル・エスカレーター
中環から坂の上へ続く全長約800mの屋外エスカレーター。沿道のソーホーは、洒落たバーや飲食店が並ぶ散策エリア。
Googleマップ →
⭐
HKI 04港の渡し船
スターフェリー
1888年から就航する港の渡し船で、九龍側の尖沙咀と香港島を結ぶ。手頃な運賃で、ビクトリア・ハーバーを海上から眺められる。
Googleマップ →
HKI 05海辺の町
赤柱（スタンレー）
香港島南岸の海辺の町。土産物が並ぶスタンレー・マーケットと、海沿いの飲食店が並ぶプロムナードを散策できる。
Googleマップ →
HKI 06水族館＆遊園地
オーシャンパーク
海を見下ろす丘陵地に広がる、水族館とアトラクションが一体の大型パーク。パンダの展示でも知られ、一日遊べる。
Googleマップ →

九龍

尖沙咀のハーバーフロントから、露店街、道教寺院、文化施設までが近い距離に集まる。香港らしい熱気と生活感を味わえる
アクセス
日本から直行便で約4〜5時間
空港↔市内
エアポートエクスプレスで九龍駅まで約20分
ベストシーズン
10〜12月
名物グルメ
煲仔飯・雞蛋仔・カレー魚蛋
市内交通
MTR・バス・スターフェリー
⭐
KLN 01ハーバービュー
尖沙咀プロムナード
ビクトリア・ハーバー沿いの遊歩道で、対岸の高層ビル群を一望できる。夜は建物が光と音で演出される催しも人気。
Googleマップ →
⭐
KLN 02夜の露店街
廟街（テンプルストリート）
油麻地から続く、夜に開く露店市場。衣類や雑貨、屋台の海鮮料理、占い師の店が通りに並び、香港らしい夜の熱気を感じる。
Googleマップ →
KLN 03値切りの市場
女人街
旺角の通菜街に並ぶ、衣類・雑貨・土産物の露店街。値札のない店では値切り交渉も楽しみのひとつで、夜まで賑わう。
Googleマップ →
KLN 04願掛けの寺
黄大仙祠
願いが叶うと信じられる道教寺院。朱塗りの伽藍が高層団地を背に建ち、新年には線香を手に祈る参拝客が絶えない。
Googleマップ →
KLN 05静寂の庭園
志蓮浄苑・南蓮園池
唐代様式の木造建築で再建された仏教寺院と、隣接する南蓮園池の庭園。高層ビルが見えるなかの静けさが際立つ。
Googleマップ →
KLN 06故宮コレクション
香港故宮文化博物館
西九龍文化区にある、北京の故宮博物院の収蔵品を展示する博物館。ビクトリア・ハーバーに面した建物も見どころ。
Googleマップ →

ランタオ島

空港のある大きな島で、天壇大仏や棚屋の漁村、ディズニーランドが点在する。高層ビルの街と対照的な、のんびりした景色
アクセス
日本から直行便で約4〜5時間
空港↔市内
空港は島の北部。MTR東涌線・バスで各所へ
ベストシーズン
10〜12月
名物グルメ
大澳の干物・海産物の屋台
市内交通
MTR・バス・ケーブルカー
⭐
LAN 01巨大青銅仏
天壇大仏
高さ約34mの青銅製の座像が、ランタオ島の山上に建つ。階段を上って足元まで近づけ、隣にはポーリン寺（寶蓮禪寺）がある。
Googleマップ →
LAN 02空中散歩
昂坪360
ケーブルカーで海と山を越え、昂坪の高原まで約25分の空中散歩。足元がガラス張りのクリスタルキャビンも選べる。
Googleマップ →
LAN 03水上の漁村
大澳（タイオー）
水上に杭を組んだ棚屋が並ぶ古い漁村。小舟で水路をゆったり巡ったり、干物や海産物の屋台を食べ歩いたりできる。
Googleマップ →
LAN 04夢の国
香港ディズニーランド
ランタオ島のディズニーパーク。「アナと雪の女王」や「アイアンマン」などのエリアがあり、コンパクトで回りやすい。
