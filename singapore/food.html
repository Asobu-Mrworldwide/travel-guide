シンガポールグルメ

カテゴリー
エリア限定
No.1
チキンライス（海南鶏飯）
国民食
鶏の茹で汁で炊いたご飯にしっとり茹で鶏を乗せ、チリ・ジンジャー・ダークソイの3種ソースで食べる国民食。ホーカーなら1皿600円前後。マックスウェルFCの天天海南鶏飯が有名店。

No.2
チリクラブ
名物シーフード
大ぶりの蟹を甘辛いチリソースで豪快に炒めたシンガポール名物。ソースを揚げパン（マントウ）に付けて食べるのがお約束。時価で1杯1万円前後と高いが、旅のハイライトになる一皿。
詳しく調べる →
No.3
ラクサ
ココナッツ麺
ココナッツミルクとスパイスの効いた濃厚スープ麺。プラナカン（中華×マレー）文化が生んだ味で、エビの旨味とほのかな辛さがクセになる。カトン地区のラクサが本場として有名。
詳しく調べる →
No.4
バクテー（肉骨茶）
胡椒スープ
骨付き豚肉を胡椒とニンニクでじっくり煮込んだスープ。シンガポール式は胡椒が効いた澄んだスープが主流で、朝食や〆にも人気。ご飯と油條（揚げパン）を浸して食べる。
詳しく調べる →
No.5
ホッケンミー
ホーカー定番
エビの出汁を吸わせた太麺と米麺のミックスを、エビ・イカと一緒に炒めた焼きそば。ライムを搾りサンバルチリを混ぜて食べる。ホーカーの実力が出る定番メニュー。
詳しく調べる →
No.6
サテー
炭火串焼き
甘めのピーナッツソースで食べる炭火の串焼き。鶏・牛・羊から選べ、10本単位で頼むのが基本。夜だけ屋台が並ぶラオパサのサテー通りは観光客に大人気。
詳しく調べる →
No.7
ロティプラタ
インド系朝食
サクサクもちもちの薄焼きパンをカレーに浸して食べるインド系グルメ。チーズや卵入りなどバリエーション豊富で、朝食にも夜食にも合う。1枚150円前後と財布に優しい。
詳しく調べる →
No.8
キャロットケーキ（菜頭粿）
名前に騙されるな
ケーキでも人参でもなく、大根餅を卵と一緒に炒めたホーカー料理。白（プレーン）と黒（甘い醤油味）の2種類がある。名前のギャップも含めてシンガポールらしい一皿。
詳しく調べる →
No.9
カヤトースト
定番朝食
ココナッツジャム（カヤ）とバターを挟んだカリカリトーストに、半熟卵と練乳コーヒー（コピ）を合わせるシンガポールの朝食セット。半熟卵に醤油を垂らしてトーストを浸すのが現地流。
詳しく調べる →
No.10
アイスカチャン
極彩色かき氷
小豆・ゼリー・コーンの上にかき氷を山盛りにし、カラフルなシロップをかけた南国かき氷。見た目のインパクトは絶大で、常夏の食べ歩きの合間のクールダウンに最適。
詳しく調べる →
No.11
プラナカン菓子（クエ）
映えスイーツ
ココナッツと米粉で作るカラフルな伝統菓子。パンダンリーフの緑や鮮やかなピンクの層が美しく、もちもち食感で日本人の口にも合う。お土産にもおすすめ。
詳しく調べる →
No.12
シンガポールスリング
元祖カクテル
ラッフルズホテルのバーで生まれたジンベースの真っ赤なカクテル。発祥のロングバーで飲むと1杯4,000円超えだが、殻付きピーナッツ食べ放題（殻は床に捨てるのが伝統）込みの特別な体験。
詳しく調べる →
No.13
フィッシュヘッド・カレー
インパクト抜群の名物
大きな魚の頭を丸ごとカレーで煮込んだ、シンガポール発祥の超有名名物料理。リトルインディアなどのインド料理店だけでなく、中華系レストランでも定番のインパクト抜群な大皿料理。
詳しく調べる →
No.14
ペーパーチキン
紙包み焼きの中華グルメ
特製のタレに漬け込んだ鶏肉をパラフィン紙で包んで揚げた料理。旨味と肉汁が紙の中に閉じ込められており、日本人観光客にも熱狂的なファンが多い中華グルメ。
詳しく調べる →
No.15
カヤボール
一口サイズのB級スイーツ
カヤトーストに使われる「カヤジャム」を、一口サイズの人形焼のような生地の中に閉じ込めたB級スイーツ。ホーカーや駅のスタンドで手軽に買える、ローカルおやつ。
詳しく調べる →
No.16
コピ／テ
シンガポール流コーヒー・紅茶
カヤトーストと一緒に必ず紹介すべき、シンガポール流の伝統的なコーヒー（コピ）と紅茶（テ）。練乳やエバミルクを入れる独特の注文ルール（「コピ・C」「コピ・O」など）がある。
詳しく調べる →
No.17
タイガービール
国民的ビール
シンガポールスリング（カクテル）に並ぶ、シンガポール発祥の国民的ビール。東南アジアの気候に合うすっきりとした味わいで、チリクラブやサテーとの相性が抜群。
